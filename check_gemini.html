Antigravity Geminiチャット診断 v1.2.0

AntigravityのGeminiチャットが動作しない場合、このページの診断スクリプトを使って原因を特定し、解決できます。

1. まず確認すること

⚠️ 最も多い原因

個人のGmailアカウントでログインしていますか？
Antigravityは組織アカウント（会社・学校のGoogle Workspace）では動作しません。
必ず @gmail.com のアカウントを使用してください。

1 Antigravityを再起動してみる

多くの問題は再起動で解決します。Antigravityを完全に終了し、もう一度起動してください。

2 チャット欄で「continue」と入力

エージェントが固まっている場合、「continue」または「proceed」と入力すると復帰することがあります。

3 それでも動かない場合 → 診断スクリプトを実行

下記のスクリプトを実行して、システム環境に問題がないか確認してください。

2. 診断スクリプト

スクリプトがチェックする項目

項目 なぜ必要？ 問題がある場合
glibc Linuxの基本ライブラリ。古いとAntigravityが起動しない OSのアップグレードが必要
GLIBCXX C++ライブラリ。古いと一部機能が動かない OSのアップグレードが必要
Chrome ブラウザエージェント機能とGoogle認証に使用 Chromeをインストール
Antigravity 本体がインストールされているか確認 再インストール
設定ディレクトリ 認証情報やユーザー設定の保存場所 初回セットアップを実行
ネットワーク Gemini APIへの接続が必要 ネットワーク設定を確認
プロセス Antigravityが正常に動作しているか 再起動を試す

スクリプトをダウンロード・実行

#!/bin/bash

# ============================================
# Antigravity Geminiチャット診断スクリプト
# Version: 1.2.0
# ============================================
#
# 【使い方】
# 1. このスクリプトをダウンロードまたはコピー
# 2. ターミナルで実行権限を付与: chmod +x check_antigravity_gemini.sh
# 3. 実行: ./check_antigravity_gemini.sh
# 4. 結果を確認し、表示される指示に従って問題を修正
#
# ============================================

VERSION="1.2.0"

# 色設定
GREEN='\033[0;32m'
YELLOW='\033[1;33m'
RED='\033[0;31m'
BLUE='\033[0;34m'
CYAN='\033[0;36m'
BOLD='\033[1m'
NC='\033[0m'

# 結果を保存する配列
declare -a ERRORS_LIST
declare -a WARNINGS_LIST
declare -a FIXES_LIST

echo ""
echo -e "${BLUE}${BOLD}╔════════════════════════════════════════════════════════════╗${NC}"
echo -e "${BLUE}${BOLD}║   Antigravity Geminiチャット診断スクリプト v${VERSION}        ║${NC}"
echo -e "${BLUE}${BOLD}╚════════════════════════════════════════════════════════════╝${NC}"
echo ""
echo -e "診断開始: $(date '+%Y-%m-%d %H:%M:%S')"
echo -e "${CYAN}━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━${NC}"
echo ""

# ============================================
# 1. glibcバージョン確認
# ============================================
echo -e "${BLUE}${BOLD}[1/7] glibcバージョン確認${NC}"
echo -e "      Linuxの基本ライブラリです。Antigravityには 2.28以上が必要です。"
echo ""

GLIBC_VERSION=$(ldd --version 2>&1 | head -n1 | grep -oP '\d+\.\d+' | head -1)
if [ -n "$GLIBC_VERSION" ]; then
    REQUIRED="2.28"
    if [ "$(printf '%s\n' "$REQUIRED" "$GLIBC_VERSION" | sort -V | head -n1)" = "$REQUIRED" ]; then
        echo -e "  ${GREEN}✓ OK: glibc $GLIBC_VERSION${NC}"
    else
        echo -e "  ${RED}✗ エラー: glibc $GLIBC_VERSION（2.28以上が必要）${NC}"
        ERRORS_LIST+=("glibcのバージョンが古い ($GLIBC_VERSION)")
        FIXES_LIST+=("【glibc】OSを新しいバージョンにアップグレードしてください（Ubuntu 20.04以上、Debian 10以上推奨）")
    fi
else
    echo -e "  ${RED}✗ エラー: glibcバージョンを取得できません${NC}"
    ERRORS_LIST+=("glibcバージョン取得失敗")
fi
echo ""

# ============================================
# 2. GLIBCXXバージョン確認
# ============================================
echo -e "${BLUE}${BOLD}[2/7] GLIBCXXバージョン確認${NC}"
echo -e "      C++標準ライブラリです。3.4.25以上が必要です。"
echo ""

# 複数のパスを試す
LIBSTDCXX_PATHS=(
    "/usr/lib/x86_64-linux-gnu/libstdc++.so.6"
    "/usr/lib64/libstdc++.so.6"
    "/lib/x86_64-linux-gnu/libstdc++.so.6"
)
GLIBCXX_VERSION=""
for libpath in "${LIBSTDCXX_PATHS[@]}"; do
    if [ -f "$libpath" ]; then
        GLIBCXX_VERSION=$(strings "$libpath" 2>/dev/null | grep GLIBCXX | sort -V | tail -1 | grep -oP '\d+\.\d+\.\d+')
        break
    fi
done

if [ -n "$GLIBCXX_VERSION" ]; then
    REQUIRED="3.4.25"
    if [ "$(printf '%s\n' "$REQUIRED" "$GLIBCXX_VERSION" | sort -V | head -n1)" = "$REQUIRED" ]; then
        echo -e "  ${GREEN}✓ OK: GLIBCXX $GLIBCXX_VERSION${NC}"
    else
        echo -e "  ${RED}✗ エラー: GLIBCXX $GLIBCXX_VERSION（3.4.25以上が必要）${NC}"
        ERRORS_LIST+=("GLIBCXXのバージョンが古い ($GLIBCXX_VERSION)")
        FIXES_LIST+=("【GLIBCXX】libstdc++を更新してください: sudo apt update && sudo apt install libstdc++6")
    fi
else
    echo -e "  ${YELLOW}△ 警告: GLIBCXXバージョンを確認できません${NC}"
    WARNINGS_LIST+=("GLIBCXXバージョン確認失敗（パスが異なる可能性）")
fi
echo ""

# ============================================
# 3. Chromeブラウザ確認
# ============================================
echo -e "${BLUE}${BOLD}[3/7] Google Chrome確認${NC}"
echo -e "      ブラウザエージェント機能とGoogle認証に使用します。"
echo ""

CHROME_FOUND=0
CHROME_PATH=""
CHROME_VERSION=""

# 検出方法1: コマンド
for cmd in google-chrome google-chrome-stable chrome; do
    if command -v $cmd &> /dev/null; then
        CHROME_PATH=$(command -v $cmd)
        CHROME_VERSION=$($cmd --version 2>/dev/null)
        CHROME_FOUND=1
        break
    fi
done

# 検出方法2: 直接パス
if [ $CHROME_FOUND -eq 0 ]; then
    for path in /opt/google/chrome/chrome /usr/bin/google-chrome /usr/bin/google-chrome-stable /snap/bin/google-chrome; do
        if [ -x "$path" ]; then
            CHROME_PATH="$path"
            CHROME_VERSION=$("$path" --version 2>/dev/null)
            CHROME_FOUND=1
            break
        fi
    done
fi

# 検出方法3: snap
if [ $CHROME_FOUND -eq 0 ] && command -v snap &> /dev/null; then
    if snap list 2>/dev/null | grep -q "google-chrome"; then
        CHROME_PATH="snap:google-chrome"
        CHROME_VERSION="snap版"
        CHROME_FOUND=1
    fi
fi

# 検出方法4: flatpak
if [ $CHROME_FOUND -eq 0 ] && command -v flatpak &> /dev/null; then
    if flatpak list 2>/dev/null | grep -qi "chrome"; then
        CHROME_PATH="flatpak:chrome"
        CHROME_VERSION="flatpak版"
        CHROME_FOUND=1
    fi
fi

# 検出方法5: .desktopファイル
if [ $CHROME_FOUND -eq 0 ]; then
    DESKTOP_FILE=$(find /usr/share/applications ~/.local/share/applications -name "*chrome*.desktop" 2>/dev/null | head -1)
    if [ -n "$DESKTOP_FILE" ]; then
        CHROME_PATH=$(grep -oP '(?<=Exec=)[^ ]+' "$DESKTOP_FILE" 2>/dev/null | head -1)
        if [ -n "$CHROME_PATH" ] && [ -x "$CHROME_PATH" ]; then
            CHROME_VERSION="デスクトップエントリから検出"
            CHROME_FOUND=1
        fi
    fi
fi

if [ $CHROME_FOUND -eq 1 ]; then
    echo -e "  ${GREEN}✓ OK: Chrome検出${NC}"
    echo -e "      バージョン: $CHROME_VERSION"
    echo -e "      パス: $CHROME_PATH"
elif command -v chromium-browser &> /dev/null || command -v chromium &> /dev/null; then
    CHROMIUM_VERSION=$(chromium-browser --version 2>/dev/null || chromium --version 2>/dev/null)
    echo -e "  ${YELLOW}△ 警告: Chromiumを検出（$CHROMIUM_VERSION）${NC}"
    echo -e "      → Google Chromeを推奨します"
    WARNINGS_LIST+=("ChromiumはインストールされていますがGoogle Chromeを推奨")
else
    echo -e "  ${RED}✗ エラー: Google Chromeが見つかりません${NC}"
    ERRORS_LIST+=("Google Chromeがインストールされていない")
    FIXES_LIST+=("【Chrome】以下のコマンドでインストール:
    wget https://dl.google.com/linux/direct/google-chrome-stable_current_amd64.deb
    sudo dpkg -i google-chrome-stable_current_amd64.deb
    sudo apt-get install -f")
fi
echo ""

# ============================================
# 4. Antigravityインストール確認
# ============================================
echo -e "${BLUE}${BOLD}[4/7] Antigravityインストール確認${NC}"
echo -e "      Antigravity本体がインストールされているか確認します。"
echo ""

AG_FOUND=0
AG_PATH=""

if command -v antigravity &> /dev/null; then
    AG_PATH=$(command -v antigravity)
    AG_VERSION=$(antigravity --version 2>/dev/null || echo "バージョン取得不可")
    AG_FOUND=1
elif [ -x /usr/bin/antigravity ]; then
    AG_PATH="/usr/bin/antigravity"
    AG_FOUND=1
elif [ -x /usr/local/bin/antigravity ]; then
    AG_PATH="/usr/local/bin/antigravity"
    AG_FOUND=1
elif [ -x /opt/antigravity/antigravity ]; then
    AG_PATH="/opt/antigravity/antigravity"
    AG_FOUND=1
fi

if [ $AG_FOUND -eq 1 ]; then
    echo -e "  ${GREEN}✓ OK: Antigravityインストール済み${NC}"
    echo -e "      パス: $AG_PATH"
else
    echo -e "  ${RED}✗ エラー: Antigravityが見つかりません${NC}"
    ERRORS_LIST+=("Antigravityがインストールされていない")
    FIXES_LIST+=("【Antigravity】インストールスクリプトを実行してください（index.htmlを参照）")
fi
echo ""

# ============================================
# 5. 設定ディレクトリ確認
# ============================================
echo -e "${BLUE}${BOLD}[5/7] 設定ディレクトリ確認${NC}"
echo -e "      認証情報とユーザー設定の保存場所を確認します。"
echo ""

CONFIG_DIRS=(
    "$HOME/.config/Antigravity"
    "$HOME/.config/antigravity"
    "$HOME/.antigravity"
)
CONFIG_FOUND=0
CONFIG_PATH=""

for DIR in "${CONFIG_DIRS[@]}"; do
    if [ -d "$DIR" ]; then
        CONFIG_PATH="$DIR"
        CONFIG_FOUND=1
        echo -e "  ${GREEN}✓ 設定ディレクトリ発見: $DIR${NC}"

        # 中身を確認
        if [ -d "$DIR/User" ]; then
            echo -e "      ${GREEN}✓ ユーザー設定あり${NC}"
        fi

        # 認証関連ファイルを探す
        AUTH_FILES=$(find "$DIR" -name "*.json" -o -name "*auth*" -o -name "*credential*" 2>/dev/null | head -3)
        if [ -n "$AUTH_FILES" ]; then
            echo -e "      ${GREEN}✓ 認証関連ファイルあり${NC}"
        else
            echo -e "      ${YELLOW}△ 認証ファイルが見つかりません${NC}"
            WARNINGS_LIST+=("認証ファイルが見つかりません - 再ログインが必要かもしれません")
        fi
        break
    fi
done

if [ $CONFIG_FOUND -eq 0 ]; then
    echo -e "  ${YELLOW}△ 警告: 設定ディレクトリが見つかりません${NC}"
    echo -e "      → Antigravityを一度起動してセットアップを完了してください"
    WARNINGS_LIST+=("設定ディレクトリが存在しない - 初回セットアップが必要")
    FIXES_LIST+=("【設定】Antigravityを起動して初回セットアップを完了してください")
fi
echo ""

# ============================================
# 6. ネットワーク接続確認
# ============================================
echo -e "${BLUE}${BOLD}[6/7] ネットワーク接続確認${NC}"
echo -e "      インターネットとGemini APIへの接続を確認します。"
echo ""

# インターネット接続
if ping -c 1 -W 3 google.com &> /dev/null; then
    echo -e "  ${GREEN}✓ インターネット接続: OK${NC}"
else
    echo -e "  ${RED}✗ エラー: インターネットに接続できません${NC}"
    ERRORS_LIST+=("インターネット接続なし")
    FIXES_LIST+=("【ネットワーク】インターネット接続を確認してください")
fi

# Gemini APIエンドポイント
if command -v curl &> /dev/null; then
    HTTP_CODE=$(curl -s --max-time 5 -o /dev/null -w "%{http_code}" https://generativelanguage.googleapis.com 2>/dev/null)
    if [ "$HTTP_CODE" = "200" ] || [ "$HTTP_CODE" = "403" ] || [ "$HTTP_CODE" = "404" ]; then
        echo -e "  ${GREEN}✓ Gemini API: 到達可能 (HTTP $HTTP_CODE)${NC}"
    else
        echo -e "  ${YELLOW}△ Gemini API: 応答なし (HTTP $HTTP_CODE)${NC}"
        WARNINGS_LIST+=("Gemini APIエンドポイントへの接続を確認できません")
    fi
else
    echo -e "  ${YELLOW}△ curlがないためAPI確認をスキップ${NC}"
fi
echo ""

# ============================================
# 7. プロセス確認
# ============================================
echo -e "${BLUE}${BOLD}[7/7] Antigravityプロセス確認${NC}"
echo -e "      現在Antigravityが実行中か確認します。"
echo ""

AG_PROCS=$(pgrep -fa "antigravity|Antigravity" 2>/dev/null | grep -v "check_antigravity" | head -5)
if [ -n "$AG_PROCS" ]; then
    echo -e "  ${GREEN}✓ Antigravityプロセス実行中:${NC}"
    echo "$AG_PROCS" | while read line; do
        echo -e "      $line"
    done
else
    echo -e "  ${YELLOW}△ Antigravityプロセスは実行されていません${NC}"
    echo -e "      → 診断後にAntigravityを起動してください"
fi
echo ""

# ============================================
# 診断結果サマリー
# ============================================
echo -e "${CYAN}━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━${NC}"
echo ""
echo -e "${BLUE}${BOLD}【診断結果サマリー】${NC}"
echo ""

ERROR_COUNT=${#ERRORS_LIST[@]}
WARNING_COUNT=${#WARNINGS_LIST[@]}

if [ $ERROR_COUNT -eq 0 ] && [ $WARNING_COUNT -eq 0 ]; then
    echo -e "${GREEN}${BOLD}✓ すべてのチェックに合格しました！${NC}"
    echo ""
    echo -e "システム環境に問題は見つかりませんでした。"
    echo -e "それでもGeminiチャットが動作しない場合は、以下を試してください："
    echo ""
    echo -e "${CYAN}【次のステップ】${NC}"
    echo -e "  1. Antigravityを完全に終了して再起動"
    echo -e "  2. 右下のプロフィールアイコン → Sign Out → Sign In"
    echo -e "  3. ${BOLD}個人のGmailアカウント${NC}(@gmail.com)でログイン"
    echo -e "     ※ 組織アカウント(会社・学校)では動作しません"
    echo -e "  4. チャット欄で「continue」と入力してみる"
    echo ""
elif [ $ERROR_COUNT -eq 0 ]; then
    echo -e "${YELLOW}${BOLD}△ ${WARNING_COUNT}件の警告があります${NC}"
    echo ""
    echo "警告一覧:"
    for i in "${!WARNINGS_LIST[@]}"; do
        echo -e "  ${YELLOW}$((i+1)). ${WARNINGS_LIST[$i]}${NC}"
    done
    echo ""
    echo -e "警告は必ずしも問題ではありませんが、確認することをお勧めします。"
else
    echo -e "${RED}${BOLD}✗ ${ERROR_COUNT}件のエラー、${WARNING_COUNT}件の警告${NC}"
    echo ""

    if [ $ERROR_COUNT -gt 0 ]; then
        echo -e "${RED}エラー一覧:${NC}"
        for i in "${!ERRORS_LIST[@]}"; do
            echo -e "  ${RED}$((i+1)). ${ERRORS_LIST[$i]}${NC}"
        done
        echo ""
    fi

    if [ $WARNING_COUNT -gt 0 ]; then
        echo -e "${YELLOW}警告一覧:${NC}"
        for i in "${!WARNINGS_LIST[@]}"; do
            echo -e "  ${YELLOW}$((i+1)). ${WARNINGS_LIST[$i]}${NC}"
        done
        echo ""
    fi
fi

# 修正手順を表示
if [ ${#FIXES_LIST[@]} -gt 0 ]; then
    echo -e "${CYAN}━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━${NC}"
    echo ""
    echo -e "${BLUE}${BOLD}【修正手順】${NC}"
    echo ""
    for i in "${!FIXES_LIST[@]}"; do
        echo -e "${BOLD}$((i+1)). ${FIXES_LIST[$i]}${NC}"
        echo ""
    done
    echo -e "修正後、このスクリプトを再実行して確認してください。"
fi

echo ""
echo -e "${CYAN}━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━${NC}"
echo -e "診断完了: $(date '+%Y-%m-%d %H:%M:%S')"
echo ""

ステップ2: ターミナルを開いて以下を実行 
# ダウンロードした場合

ステップ3: 結果を確認し、表示される指示に従って問題を修正

3. よくある問題と解決方法

🔴 glibc / GLIBCXXのバージョンが古い ▼

原因: OSが古いバージョンのため、必要なライブラリがありません。

必要なバージョン:

  • glibc 2.28以上（Ubuntu 20.04、Debian 10以上に含まれる）
  • GLIBCXX 3.4.25以上

解決方法:

# OSのアップグレード（推奨）
sudo apt update && sudo apt upgrade -y
sudo do-release-upgrade  # Ubuntuの場合

# または libstdc++の更新
sudo apt install libstdc++6
🔴 Google Chromeがインストールされていない ▼

原因: AntigravityはGoogle認証とブラウザエージェント機能にChromeを使用します。

解決方法:

# Google Chromeをインストール
wget https://dl.google.com/linux/direct/google-chrome-stable_current_amd64.deb
sudo dpkg -i google-chrome-stable_current_amd64.deb

# 依存関係エラーが出た場合
sudo apt-get install -f
🟡 認証ファイルが見つからない / ログインできない ▼

原因: Googleアカウントでのログインが完了していないか、認証情報が破損しています。

重要: 個人のGmailアカウント（@gmail.com）が必須です。
会社や学校のGoogle Workspaceアカウントでは動作しません。

解決方法:

  1. Antigravityを起動
  2. 右下のプロフィールアイコンをクリック
  3. 「Sign Out」をクリック
  4. 「Sign In」をクリック
  5. 個人のGmailアカウントでログイン

それでもダメな場合（設定リセット）:

# 設定をバックアップしてリセット
mv ~/.config/Antigravity ~/.config/Antigravity.backup
# Antigravityを再起動して最初からセットアップ
🟡 チャットが固まる / 応答しない ▼

原因: エージェントが処理中に停止することがあります。

解決方法:

  1. チャット欄に continue または proceed と入力
  2. それでも動かない場合: Ctrl+Shift+P → 「Restart Agent Service」
  3. 最終手段: Antigravityを完全に終了して再起動

モデルを変更する:

右下のモデルセレクターで、より軽いモデル（Gemini 3 Pro Standard）に切り替えてみてください。

🔵 すべてOKなのに動かない ▼

診断スクリプトで問題が見つからない場合は、以下を順番に試してください:

  1. Antigravityを完全に終了して再起動
  2. Googleアカウントで再ログイン（個人Gmail必須）
  3. Chrome拡張機能の確認: Antigravityの指示に従って拡張機能をインストール
  4. ファイアウォール/プロキシの確認: 会社ネットワークでブロックされている可能性
  5. VPNを使用している場合: 一度オフにして試す

バグ報告:

  • Antigravity内: プロフィールアイコン → 「Report Issue」
  • Agent Manager内: 「Provide Feedback」リンク
